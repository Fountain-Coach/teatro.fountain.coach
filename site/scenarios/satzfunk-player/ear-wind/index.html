TEATRO SCENARIO · CSOUND DSL 0.1

SatzfunkPlayer, heard by Ear, shaping wind

This resource describes one bounded live patch: SatzfunkPlayer's live PCM feeds Ear; Ear's measured RMS maps to the Csound FIELD control wind_mix. The Player owns playback, admission, and start/stop runtime. Teatro owns this semantic scenario.

Candidate · not admitted · not live-accepted. The route exposes the versioned scenario and its Player runtime contract. A secure same-origin released track and a witnessed staging run are still required for live acceptance. Nothing starts automatically.

Declared control path

SatzfunkPlayer.01.audio → Ear.Player.01.audio
Ear.Player.01.rms → Wind.Field.01.wind_mix
Wind.Field.01.audio → Ear.Wind.01.audio

The mapping clamps RMS 0–0.20 to wind_mix 0.25–1.0, with a minimum 75 ms interval. The scenario does not claim a MIDI 2.0 Player operation; its audio path is local Web Audio and Csound host routing.
