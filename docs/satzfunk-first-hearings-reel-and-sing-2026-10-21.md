# Teatro and Satzfunk: First Hearings reel, live scores and sing

**21 October 2026 — architecture note, not publication proof.**

Fountain Press's [publication identity and cover navigation contract](https://github.com/Fountain-Coach/fountain-press/blob/main/docs/publication-identity-and-cover-navigation.md) distinguishes **Teatro as a producing tool**, not a work, book or collection. Its three main publication collection identities are Essays, First Readings and **First Hearings**. Do not place a fourth primary logo/book on the existing main shelf.

The desired `satzfunk.fountain.coach` domain is a **nested performing/listening station of First Hearings**. It should gain a recognizable Satzfunk logo/mark and a reel/collection of distinct released works, including historical album presentations, without replacing Teatro's existing authored [First Hearing edition](../site/editions/first-hearing/index.html). The publisher, not ad-hoc hardcoded site navigation, admits the future mark/cover/destination.

The existing private [Satzfunk archive](https://github.com/Fountain-Coach/Satzfunk/blob/main/archive/browser/index.html) already supports Bandcamp browsing and private 7VST source/text study; its public publishing projection must be filtered by actual item-level media/translation/collaborator rights. Do not mirror its private media or source-text routes.

**Web-based creation** begins from a source-addressed, rights-admitted listening item: open a private, revisioned Teatro performance proposal, score with native MIDI2/ScoreKit/AudioTalk, render the [sing](https://github.com/Fountain-Coach/sing) voice instrument or separately paid/granted AI speech, compare alternate takes in the existing Satzfunk listening interface, and accept through Reframe. A new performance is a new version/edition, never a mutation of the source. There is no currently verified URL that opens an arbitrary archive track as a real Teatro remix: don't install a fake public “Remix” control.

See [Satzfunk's additive station direction](https://github.com/Fountain-Coach/Satzfunk/blob/main/docs/scenarios/2026-10-21-public-hearing-reel-and-teatro-remix-growth.md) and [sing's proposed rehearsal handoff](https://github.com/Fountain-Coach/sing/blob/main/docs/satzfunk-teatro-rehearsal-handoff.md).

Audio and scores remain separately authored; present the calm book-first Teatro score and listening experience on iPad. Existing page, audio renderer, navigation, score witnesses, code and release remain unchanged by this note. Public DNS, host, estate publication, new logos, hosted Bandcamp replicas and AI API spending are not undertaken here.
